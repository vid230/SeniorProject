Slide 1 — Title
Hello, my name is Valeri Dimitrov, and this is my Senior Project, the AUBG Academic Progress Tracker.
The goal of the project is to help students track their academic progress and plan future results.

Slide 2 — Problem and Goal
Students need to keep track of courses, grades, credits, semesters, and GPA.
My application puts this information in one place and also helps the user explore possible future academic outcomes.

Slide 3 — System Architecture
The application is built with C#, Blazor, Entity Framework Core, and SQLite.
The user interface is separated from the business logic and the database, which makes the project easier to maintain and test.

Slide 4 — Data Model
The main database entities are Course and Semester.
One semester can contain many courses, and each course belongs to one semester through a foreign key.

Slide 5 — Features Completed
So far, the application supports adding, editing, deleting, and viewing courses and semesters.
It also calculates cumulative GPA, semester GPA, earned credits, attempted credits, and completed courses.

Slide 6 — What-if GPA Calculator
The What-if Calculator allows the user to enter hypothetical future courses and grades.
It calculates a projected GPA without saving those hypothetical courses into the real database.

Slide 7 — Target GPA Solver
The Target GPA Solver works in the opposite direction.
The user gives a target GPA and the remaining courses, and the program searches for grades that can reach that target.

Slide 8 — Algorithm 1: Backtracking
The first main algorithm is recursive backtracking, which tries different grade combinations for the remaining courses.
I added pruning so the program can stop searching a branch when it is already impossible or unnecessary to continue.

Slide 9 — Algorithm 2: Memoization
Backtracking was still too slow for large reachable cases, because many identical subproblems were calculated again and again.
I added dynamic programming through memoization, which saves solved states and reuses them, making the solver much faster.

Slide 10 — Current Status and Next Steps
The main tracking features and the Target GPA Solver are already working.
Next, I plan to add degree progress and a prerequisite planner using a graph and topological sort, which will provide the third main algorithm.
